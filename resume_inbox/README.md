# 本地简历收件目录

请把自动化判断要使用的文本型 PDF 简历放在此目录。

- PDF 文件名可以任意。
- 脚本会忽略 README 等非 PDF 文件，并自动选择目录中唯一的 PDF。
- 如果有多份 PDF，请只保留本次要使用的一份，避免选错简历。
- PDF 原件包含个人信息，已由项目 `.gitignore` 排除，不应提交到版本控制或直接分享。

此目录中的本地 PDF 只用于岗位匹配、模型审核和招呼语事实约束。消息巡检中的“发简历”操作使用当前 Boss Web 账号页面已有的附件简历，通过标准请求卡片或“发简历”入口发送；程序不会把本目录 PDF 自动上传到 Boss，也不会读取浏览器私有数据或调用私有接口。
