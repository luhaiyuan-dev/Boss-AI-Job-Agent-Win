# Win-Web 首次使用向导

## 1. 复制与部署

先把整个 `requests-packages` 文件夹复制到目标目录，再依次双击：

1. `验证安装包.cmd`
2. `一键部署.cmd`
3. `验证环境.cmd`

`一键部署.cmd` 会先检查 PowerShell 7：已安装就直接复用，未安装则校验并解压随包的官方 7.6.4 LTS 离线包，再执行后续部署。新装的 PowerShell 7、MySQL 和 Navicat 会放到一键部署文件所在盘符的 `BossJobAssistant` 目录；Edge、VC++ 等系统组件仍使用 Windows 默认位置。已有软件只复用，不迁移。脚本会在 `requests-packages` 的父目录创建 `config` 和 `resume_inbox`；不会安装 Python。新装 MySQL 时请现场设置至少 8 位密码，配置模板仍保持用户名和密码为空。

## 2. 放置程序

把 `Boss求职助手.exe` 和 `Boss登录浏览器.exe` 复制到 `requests-packages` 的父目录。两个 EXE、`config`、`resume_inbox` 和 `requests-packages` 必须共享同一父目录。

## 3. 选择模型审核方式

只需完成一种：

- 大模型 API：编辑 `config\model_api.local.json`，填写实际 `base_url`、`model` 和 API Key，或用 `api_key_env` 指向环境变量。模板保留 `deepseek-v4-flash`，程序使用实际配置，不固定替换 API 模型。
- Codex 主导：双击 `requests-packages\安装Codex（可选）.cmd`。脚本和 EXE 都会自动识别已安装、已登录的 Codex；未登录时必须由当前 Windows 用户执行 `codex login`。此模式固定使用 `gpt-5.5`。

## 4. 配置 MySQL

编辑 `config\gui_defaults.txt`，填写当前电脑实际可用的用户名和密码。新装实例只监听 `127.0.0.1:3306`，数据库为 `boss_job_assistant`；已有实例不会被覆盖或改密。

## 5. 准备简历

在 `resume_inbox` 中只放一份带可复制文本层的 PDF。扫描图片不支持 OCR，多于一份时程序会拒绝继续。不要把真实简历放入分发包。

## 6. 登录与首次运行

双击 `Boss登录浏览器.exe`，在专用 Edge 中手动登录 Boss直聘并保持窗口开启；登录态只保存在当前电脑。然后双击 `Boss求职助手.exe`。

首次建议选择“仅填充不发送”、目标公司数 1，并核对明确的城市/岗位、薪资、公司规模和排除条件。GUI 启动时的求职意向预读是只读流程；点击“开始”后才会初始化简历、MySQL、模型和正式循环。

进入聊天、点击按钮、输入框清空都不代表发送成功；只有聊天记录出现完整的我方消息气泡才计为成功。确认失败不会自动重发。

## 7. 可选：永久删除离线部署包

确认 `验证环境.cmd` 通过、两个 EXE 能正常启动，并且 `config` 已按需填写后，可以双击 `requests-packages\delete.cmd`。该文件会立即覆盖并永久删除整个 `requests-packages`，包括安装器、部署脚本和 `delete.cmd` 自身，不进入回收站且没有撤销步骤。

删除不会卸载已经部署的软件，也不会删除父目录的两个 EXE、`config` 或 `resume_inbox`。普通恢复软件无法直接恢复已经覆盖的原文件，但 SSD、卷影副本、云同步和外部备份不属于脚本能够绝对清除的范围。检测到 `.git` 或项目源码时删除器会拒绝运行，防止误删开发目录。
