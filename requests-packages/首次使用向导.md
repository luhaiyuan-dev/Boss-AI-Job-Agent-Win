# Win-Web 首次使用向导

## 1. 校验并部署

保持项目目录结构不变，依次双击：

1. `验证安装包.cmd`
2. `一键部署.cmd`
3. `验证环境.cmd`

安装失败时查看 `requests-packages/logs/` 中最新日志。部署脚本会保护已有 MySQL：只要检测到其它 MySQL 服务或 3306 被占用，就不会覆盖数据库。

## 2. 选择模型审核方式

只需完成一种：

### 大模型 API

编辑项目根目录：

```text
config\model_api.local.json
```

脱敏模板是：

```text
config\model_api.example.json
```

填写实际 `base_url`、`model` 和 `api_key`，或用 `api_key_env` 指向环境变量。项目按配置使用模型，不会固定替换模型名。不要把真实 Key 写入 example 模板或分发包。

### Codex主导

运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\requests-packages\scripts\Install-Codex-Optional.ps1
codex login
codex login status
```

随包 Codex 是 0.133.0 Windows x64 原生版本，无需另装 Node/npm。安装与登录都可在首次部署时跳过。

## 3. 配置 MySQL

新安装实例默认只监听 `127.0.0.1:3306`，数据库为 `boss_job_assistant`，凭据为 `root/root`。配置文件在：

```text
config\gui_defaults.txt
```

如果电脑已有 MySQL，部署脚本不会覆盖它。请把这个文件或 GUI 中的主机、端口、用户名、密码、数据库改成真实值，并确保账号有创建数据库、建表和读写权限。

Navicat 只是可选查看工具。随包只含官方安装器，不含许可证、激活状态、连接和密码。

## 4. 准备简历

在项目根目录 `resume_inbox/` 中只放一份 PDF：

- 必须有可复制的文本层；扫描图片不支持 OCR。
- 目录中多于一份 PDF 时程序会拒绝继续，避免选错。
- 不要把真实简历放入分发包。

## 5. 登录项目专用 Edge

双击 `打开Boss登录Edge.cmd`，在打开的 Edge 中手动登录 Boss直聘并保持窗口开启。

项目使用自己的原生 CDP WebSocket，不使用 Selenium/Playwright 接管登录页，也不需要 EdgeDriver。登录资料保存在 `data/edge_profile_boss/`，只属于当前电脑和当前用户，禁止复制给别人。

## 6. 启动和首次安全验证

双击 `启动Boss助手.cmd`。GUI 启动后的求职意向预读是只读流程，不初始化简历、MySQL、模型或投递循环；点击“开始”后才进入正式运行。

首次建议：

- 运行模式选“仅填充不发送”。
- 目标公司数设为 1。
- 选择明确的一条“城市 / 岗位”求职意向。
- 核对薪资、公司规模、排除公司和岗位方向。
- 观察输入框内容正确后手工清理草稿，不要直接切换为真实发送。

## 7. 成功口径

进入聊天、点击按钮或输入框清空都不代表发送成功。程序只在聊天记录出现完整的我方消息气泡后计为成功；确认失败不会自动重发。

部署和环境验证阶段不会打开职位、填写草稿、调用模型或发送任何内容。
